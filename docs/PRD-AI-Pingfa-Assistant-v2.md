## 1. 项目背景

### 1.1 产品现状

Alpha-7（路径：`C:\Users\Administrator\CascadeProjects\tese`）是一个基于 React + Three.js 的纯前端工具，用户通过表单输入参数，实时生成基于 **22G101 图集**的钢筋骨架 3D 模型。当前覆盖框架梁 KL，支持自动计算锚固长度、弯钩长度、箍筋加密区等参数。

### 1.2 用户痛点

1. **理解门槛高** — 平法编号（N4C16、C8@100/200(2)、通长筋、架立筋）需要对照图集查阅释义，新人看不懂
2. **规则不透明** — 锚固长度、加密区等计算逻辑隐藏在代码/图集中，用户无法交互式提问「为什么是这个值」
3. **学习路径缺失** — 工具只有 3D 展示和表单输入，没有教学引导
4. **图集查阅不便** — 22G101 共 3 册数百页，资深工程师查阅冷门构造也要翻半天

### 1.3 产品目标

在 Alpha-7 中嵌入一个 **AI 平法学习助手**，让用户直接在工具内以自然语言提问，获得基于 22G101 图集的解释和构造建议。

### 1.4 战略价值

- **差异化**：市面钢筋 3D 可视化工具极少带内嵌教学 AI
- **降低门槛**：吸引结构实习生、高校学生群体
- **技术铺路**：为规范条文 → 3D 高亮联动、智能参数推荐积累能力
- **模型中立**：用户自带 API Key，无合规/成本风险

## 9. 风险与约束

| 风险 | 影响 | 概率 | 缓解方案 |
|------|------|------|---------|
| **CORS 限制** — 多数国内 API 不支持浏览器端直接调用 | 纯前端方案不可行 | 高 | Phase 1 仅用 DeepSeek（已确认支持）；Phase 2 引入 Vercel 代理 |
| **API Key 泄露** — localStorage 可能被 XSS 窃取 | 安全风险 | 低 | Key 仅存本地，不上传；建议用户使用限量 Key |
| **模型 API 停服/变更** — 服务商修改接口或关闭 | 功能不可用 | 低 | Provider 架构方便切换；切换模型即可 |
| **对话 Token 膨胀** — 长对话消耗过多上下文 | 费用 + 延迟增加 | 中 | 自动截断早期消息（保留最近 10 轮） |
| **用户无 API Key** — 没有国内模型的 Key | 功能无法使用 | 中 | 首次打开引导配置流程；文档教用户获取免费额度 |
| **3D 场景性能下降** — AI 面板影响 WebGL 渲染 | 体验下降 | 低 | 懒加载 + 独立渲染 + 帧率监控 |

### 已知约束

1. **纯前端部署限制** — GitHub Pages 不支持服务端逻辑，CORS 问题必须在前端层或代理层解决
2. **无后端代理** — 当前项目无后端服务，所有 API 调用必须由浏览器直发或通过第三方代理
3. **用户自带 Key** — 不内置任何模型 Key，用户必须自行申请
4. **预算为零** — 不可引入任何付费服务（如 Serverless 函数）除非 Phase 2 评估确认后
