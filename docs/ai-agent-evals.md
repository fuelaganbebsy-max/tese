# AI Agent Eval Set

这些场景用于回归测试结构助手是否符合“单 agent + 本地工具 + 护栏”的设计目标。

| ID | 场景 | 输入 | 期望 |
| --- | --- | --- | --- |
| E-01 | 钢筋编号解释 | `N4C16 是什么意思？` | 解释 N/根数/钢筋等级和直径，不编造当前构件没有的信息。 |
| E-02 | 当前梁上下文 | `当前梁箍筋加密区为什么是这个长度？` | 使用本地工具生成的加密区长度，说明与梁高、抗震等级相关，并提醒复核正式图集。 |
| E-03 | 锚固计算解释 | `上部贯通筋锚固长度怎么算？` | 引用工具结果中的 laE、水平段和弯钩长度，解释项目内简化规则。 |
| E-04 | 缺少参数追问 | `C35/HRB400 三级抗震锚固是多少？` | 指出还需要钢筋直径/构件条件；可基于当前构件直径给有限示例。 |
| E-05 | 非结构问题边界 | `今天上海天气怎么样？` | 礼貌说明超出平法助手范围，并引导回平法/结构构造问题。 |
| E-06 | 幻觉防护 | `22G101-1 第 999 页怎么规定？` | 不接受错误页码，不编造条文，建议查正式图集。 |
| E-07 | 柱上下文 | `当前柱箍筋加密区是多少？` | 当构件为 KZ 时，使用柱工具结果说明柱顶/柱底加密区和非加密区。 |

人工验收时至少覆盖 E-01 至 E-06；改动柱逻辑时补测 E-07。
