## 1. 柱剖切面 2D 视图：上下层变截面定位修正

**文件**: `src/ui/data/ColumnDataContent.tsx`

**问题**: 当柱上下截面尺寸/偏心不一致时，剖切面（右下角）中上层柱箍筋会缩小，但混凝土截面未同步缩小，且偏心时对齐边未固定。

**处理**:
- 以下层截面尺寸（`params.b`/`params.h`）作为 SVG 视图的固定参考系。
- 上层截面矩形和纵筋仍使用上层尺寸与偏移，但映射到下层参考系中绘制。
- 结果：居中时上层截面随尺寸缩小；偏心时对齐边保持不动，仅未对齐边收缩。

## 2. 柱变截面纵筋：弯折通上条件与锚固构造

**文件**: `src/geometry/buildColumnLongitudinal.ts`

### 2.1 增加变截面斜弯判定
- 按 22G101-1 7.2.7，当水平偏移 Δ 与梁高 hb 之比 **≤ 1/6** 时，纵筋可斜弯通上。
- 当 **Δ/hb > 1/6** 时，下柱筋与上柱筋断开，不再拉通。

### 2.2 不能拉通钢筋的锚固做法
- **下柱筋**：沿原截面位置垂直伸至上截面下端（`trans.end - cover`），然后向截面内侧水平弯折 **12d**，形成倒 L 形锚固。
- **上柱筋**：从同一高度向下延伸 **1.2laE** 起筋，再直通柱顶并按柱顶锚固构造处理。

### 2.3 细节调整
- 下柱筋不再在梁高范围内斜弯到上层位置，而是保持垂直。
- 下柱筋终点考虑保护层厚度，从 `trans.end` 改为 `trans.end - params.cover`。
- 上柱起筋点同步从 `lowerEnd` 向下 1.2laE。

## 3. 梁柱节点楼板

**文件**: `src/scene/ColumnScene.tsx`

### 3.1 新增 `ColumnSlabs` 组件
- 在 `f = 0, 1, ..., floors` 每个梁柱节点处生成一块楼板。
- 楼板厚度固定 **120mm**。
- 平面尺寸与两个方向梁外缘平齐：
  - X 向宽度 = `b + 2 × BEAM_PROJECTION`
  - Z 向深度 = `h + 2 × BEAM_PROJECTION`
- 板顶面与梁顶面平齐，中心位于 `floorY + beamHeight - 120/2`。
- 上层节点随上层截面尺寸与偏移量联动。

### 3.2 材质与显示状态
- 颜色/透明度/粗糙度等参数与柱混凝土完全一致（`#8a9a9e`、`opacity=0.18`、`roughness=0.95` 等）。
- 显示/隐藏与 `view.showConcrete` 联动，关闭混凝土时楼板同步隐藏。
